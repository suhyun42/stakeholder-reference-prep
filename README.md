# Bindhu reference brief — GitHub Pages

1. Sign in to GitHub as suhyun42.
2. Create a public repository named bindhu-reference (or open an existing repository).
3. Extract this ZIP. Upload index.html and .nojekyll to the repository root using Add file > Upload files, then commit to main. Do not upload the ZIP itself.
4. Open Settings > Pages. Under Build and deployment, select Deploy from a branch. Choose main and / (root), then Save.
5. When deployment completes, open the link shown in Settings > Pages.

If you use the repository name bindhu-reference, the expected address is:
https://suhyun42.github.io/bindhu-reference/

This address becomes live only after you upload the files and enable GitHub Pages. GitHub Pages publishes the site publicly.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
